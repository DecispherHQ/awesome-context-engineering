# Contributing

Thanks for wanting to improve this list. The rules are short:

1. **One resource per line**, in the format:
   `- [Name](https://link) - One-line factual description ending with a period.`
2. **Alphabetical order within its section** (foundational/original items may lead a section where noted).
3. **Descriptions state facts, not marketing.** "Compresses prompts up to 20x" with a source is fine; "the best RAG framework" is not.
4. **Stay in scope.** This list is about context engineering: retrieval, memory, compression, MCP, decision records, and team knowledge for AI agents. General LLM or agent frameworks belong in the broader awesome lists linked at the bottom of the README.
5. **The project should be alive.** Archived or clearly abandoned repos are removed; link a maintained fork instead if one exists.
6. **Self-promotion is allowed if the tool is real and in scope.** Describe it the same neutral way every other entry is described. PRs that add a tool alongside edits that puff it up will be asked to split.

## Adding a guide

Long-form guides live in [`guides/`](guides/). New guides are welcome if they teach something practitioners can use, vendor-neutrally. Open an issue first describing the outline.

## Reporting problems

Broken links, dead projects, wrong descriptions: open an issue or a PR directly. Both are appreciated.
